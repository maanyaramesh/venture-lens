# VentureLens
> AI-powered startup idea validation using local LLM inference.
VentureLens analyzes a startup idea and turns it into a structured venture assessment. It evaluates market potential, competition, product requirements, business assumptions, risks, and validation experiments — helping founders identify what should be tested before investing significant time or money.
## Features
- Dynamic startup idea analysis
- Market and competition assessment
- Product and MVP recommendations
- Business model analysis
- Risk identification and severity scoring
- Validation experiment suggestions
- Hostile investor / stress-test mode
- Structured AI responses
- Local LLM inference with Ollama
- No paid AI API required

How It Works

1. The user enters a startup idea.
2. The Next.js API route sends the idea to a locally running Ollama model.
3. The model is instructed to return structured JSON.
4. The API validates and parses the response.
5. The frontend converts the analysis into an interactive dashboard.
6. Users can run a separate stress test to identify assumptions that could cause the venture to fail.

Running Locally

* Node.js

git clone https://github.com/maanyaramesh/venture-lens.git
cd venture-lens
npm install

Start Ollama

Install Ollama and pull the model used by VentureLens:

ollama pull llama3.2:3b

Start the Ollama server:

ollama serve

Start VentureLens

npm run dev

Open:

http://localhost:3000

Why Local AI?

VentureLens uses local inference instead of a paid cloud API.

This provides:

* No per-request API cost
* No startup idea sent to a third-party AI API
* Offline-capable inference
* Full control over the model and prompting pipeline

The trade-off is that inference speed and output quality depend on the user’s hardware and local model.

Engineering Highlights

Structured AI Output

Instead of treating the LLM response as unrestricted text, VentureLens requests a defined JSON structure containing the required analytical fields.

This allows the frontend to reliably render:

* Scores
* Risks
* Competition
* Business assumptions
* Experiments
* Stress-test results

Timeout Handling

Long-running local inference is handled with request timeouts and explicit error states so that an overloaded local model does not leave the UI indefinitely waiting.

Stress Testing

The stress-test feature uses the existing venture analysis as context and asks the model to challenge the highest-risk assumptions rather than simply generating additional positive analysis.

Limitations

VentureLens is an AI-assisted validation tool, not a substitute for real market research.

The quality of the analysis depends on:

* The information contained in the startup idea
* The local model’s reasoning capability
* Model size and hardware
* The accuracy of assumptions generated by the model

Real validation still requires customer interviews, experiments, competitive research, and market data.
