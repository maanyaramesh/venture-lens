# VentureLens — real local-AI build

This version is dynamic. It does NOT contain a hardcoded startup analysis.

## Zero-cost local setup

1. Install Ollama from https://ollama.com/
2. Start Ollama.
3. Pull a local model, for example:
   `ollama pull llama3.2:3b`
4. In this project:
   `npm install`
   `npm run dev`
5. Open http://localhost:3000

The Next.js route `/api/analyze` sends the user's actual idea to Ollama and requests a strict JSON schema. The dashboard renders that returned analysis.

The default is `llama3.2:3b`, chosen to keep local inference much lighter on a Mac. If you already installed another model, set it with:
`OLLAMA_MODEL=your-model npm run dev`

No paid API key is required.

## Important

Market numbers and competitor claims generated by a local model are hypotheses unless independently verified. The next production upgrade should add a research/evidence layer and citations before presenting market data as factual.

## Architecture

Browser -> Next.js Route Handler -> local Ollama -> structured Analysis JSON -> dashboard

Next.js Route Handlers are used as the server-side API layer, and Ollama supports JSON-schema constrained structured outputs.
